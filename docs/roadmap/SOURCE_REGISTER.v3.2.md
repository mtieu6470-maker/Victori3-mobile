Caveats recorded in v3.2:
- These statements are recorded for a **public** repository. The document does not claim the same rules or availability for a private repository; if visibility or plan changes, availability must be re-checked before C3 runs.
- **Prevent self-review:** if enabled, the person who starts the workflow cannot approve it. With a single trusted reviewer who also starts `workflow_dispatch`, enabling it makes the signing job impossible to approve (deadlock). Configure according to the actual number of trusted reviewers (v3.2 §4.1.2, Appendix A.3).
- Exact button labels on the GitHub mobile web UI were not verified.
