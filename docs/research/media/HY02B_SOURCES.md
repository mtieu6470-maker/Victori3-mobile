## Screening rules

- Prefer the original repository/catalogue page and a direct original-file URL.
- Require a clearly stated Public Domain/CC0 basis; exclude CC BY-NC and rights-managed commercial-image agencies.
- Minimum target for a usable source image: 1,200 px on the long edge. A source can be historically relevant but still fail this technical gate.
- For 16:9 use, prefer a crop that preserves the central historical subject. Do not stretch portrait scans.
- PD labels on Commons are a useful rights lead, not a substitute for the repository's own final jurisdiction/rights review.
